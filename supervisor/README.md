# 任务监管

独立进程负责队列、活动任务状态、训练进程树、日志落盘、指标解析、心跳和重连。

后续实现入口：

- IPC 服务与客户端：仅本机、随机令牌鉴权。
- 调度器：首版单 GPU 单任务，任务绑定安装实例。
- 进程执行器：按 `LaunchSpec.argv` 启动原生 CLI，处理 Windows 子进程树。
- 事件与日志：原始输出优先落盘，再批量提供解析指标与增量事件。
- 活动任务存储：由监管进程负责状态写入，应用后端通过 IPC 请求变更。

监管可以调用适配器公共接口解析日志与产物，但不能导入引擎内部 Python 模块。进程控制应与具体训练引擎解耦。

当前没有监管实现；不宣称现在即可在关闭窗口后保持训练。
