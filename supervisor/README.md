# 任务监管

独立进程负责队列、活动任务状态、训练进程树、日志落盘、指标解析、心跳和重连。

- 调度器：单 GPU 单任务，任务绑定安装实例；存在失联（`connection_lost`）任务时拒绝启动新任务。
- 进程执行器：按 `LaunchSpec.commands()`（前置缓存阶段 + 主训练命令）依次启动原生 CLI，处理 Windows 子进程树。
- 启动前校验：任务绑定的配置哈希、源码 revision、适配器版本与环境清单必须一致，否则拒绝执行。
- 事件与日志：原始输出优先落盘，再批量提供解析指标与增量事件；日志解析/写入异常只降级为原始日志，不中断训练。
- 任务存储：监管进程负责状态写入，经 SQLite 状态库与应用后端协作（当前无独立 IPC 服务）。

监管可以调用适配器公共接口解析日志与产物，但不能导入引擎内部 Python 模块。进程控制与具体训练引擎解耦。

实现在 `supervisor/worker.py`；关闭窗口不会中断监管与训练。
