# 参数导出格式

新建任务的「导出参数」、配置预览区的下载按钮，以及历史任务右键菜单的「导出配置」，统一先显示格式选择弹窗，再打开保存对话框。界面沿用现有弹窗、圆角、配色和按钮。

| 选择 | 文件格式 | 用途 |
| --- | --- | --- |
| LP 完整备份（默认） | `.params.json` | 保留完整表单、引擎类型、模型类型、数据集路径和参数，用于 LP 导入、迁移及历史任务复用。未填完表单也可导出。 |
| Kohya 原生参数 | `.toml` | 通过 Kohya 适配器转换为 sd-scripts 参数键名。 |
| Musubi Tuner 原生参数 | `.toml` | 通过 Musubi 适配器转换为对应模型训练脚本的参数键名，列表参数生成 TOML 数组。 |
| AI Toolkit 原生参数 | `.yaml` | 通过 AI Toolkit 适配器生成 `job/config/process` 嵌套配置，包含数据集路径。 |

弹窗实际显示「LP 完整备份」和当前引擎对应的原生格式，不提供把同一份文本仅修改扩展名的转换。格式兼容不等同于不同训练器、不同模型之间的参数语义兼容。跨引擎迁移仍需检查模型、训练器版本、支持的参数和本机路径。LP JSON 用于 LP 的导入；原生文件用于对应训练器，不能保证任意 GUI 都能直接导入。

## 原生文件的范围

原生导出是参数配置，不是完整训练任务包，不打包模型、图片、Python 环境、缓存或预览提示词文件。Kohya 与 Musubi 的导出说明及文件注释会提示单独配置数据集；Musubi 还需要执行对应模型的前置缓存流程。为避免引用不存在的文件，Kohya 参数文件不写入 LP 预览的 `dataset_config` 路径。AI Toolkit YAML 保留数据集路径，运行前同样需要确认路径和版本。

原生参数由适配器筛选、映射，因此不一定保留全部 LP 表单信息；若需要无损备份，请使用 LP JSON。原生参数导出不等同于通过训练前检测，真正提交训练仍会检查环境、模型和数据集。

## 实现约定

- `TrainingExportDialog.vue` 是两个页面共用的弹窗；打开时捕获参数快照，历史菜单始终使用右键目标任务。
- `POST /api/v1/training/export-parameters` 是只读生成接口，沿用本机会话认证，不要求引擎环境就绪或原安装实例仍存在，不启动 Python 训练进程，也不生成任务目录。
- `EngineAdapter.export_parameters(config)` 返回原生文本及说明，格式来自适配器的 `native_format`。前端不维护引擎名称或格式白名单。新增适配器可实现该方法；未实现时仍可导出 LP 备份。
- 原生生成失败时显示原因和重试按钮，不阻止 LP JSON 导出。保存失败或用户取消 Save As 时保留弹窗和已选格式，允许重试；保存过程中禁止重复提交。
- 桌面模式继续使用现有原生保存接口，浏览器模式使用下载，不改变启动和权限修复机制。

## 验证

回归覆盖实际后端的三类适配器输出、TOML 标量与列表、中文及引号路径、历史引擎实例已移除、接口认证及错误返回；真实浏览器覆盖格式弹窗、右键目标、JSON/TOML/YAML 扩展名与内容、取消与失败重试。训练器的实际运行仍需要完整环境及数据集配置，不由导出测试启动训练。
