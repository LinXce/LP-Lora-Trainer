# 历史任务与终端日志操作

## 历史训练任务

在“训练任务”列表中右键某个任务，或点击详情头部的“更多操作”，可以：

- **导出配置**：导出 `.params.json` 文件，可通过新建训练界面的“导入参数”重新使用。保存任务名称、引擎类型与安装实例、模型架构、数据集及路径、底模、输出根目录、全部已提交参数。不会把旧任务的专属输出子目录作为新任务输出根目录。
- **使用配置**：跳转到“新建训练”，自动应用历史配置；不立即启动训练、不复制旧任务状态。参数仍需重新检测后提交。原安装实例不存在时优先匹配同类型引擎，原数据集可以按登记 ID 或路径匹配；无法匹配时保留其他参数并提示重新选择，不能偷偷切换到不同类型引擎。
- **删除**：确认后永久删除训练历史记录及应用数据目录 `jobs/<任务 ID>/` 中的配置快照、运行日志和指标。只允许删除已成功、失败或停止的任务；运行、排队、停止中及连接丢失的任务禁止删除。连接丢失时必须先核实原进程已退出，再执行“确认已退出”。

删除训练历史不会删除数据集、基础模型、引擎环境、输出模型或预览图。已登记产物保留轻量输出关联信息，仍可在“训练结果”中查看、预览和发布；下拉栏会标记“任务记录已删除，产物保留”。原任务的配置此后不可再导出或复用，建议删除前先导出。

右键菜单支持 Esc、外部点击关闭和键盘操作，并自动避开窗口边缘。删除事件同步给其他已连接客户端，刷新后不会重新出现已删除任务。

## 终端日志

终端展示的是引擎环境安装会话输出，不是任意系统命令终端。

- **清空显示**：仅清空当前可见文本，保留安装历史、完整磁盘日志及读取位置。
- **删除日志**：确认后删除选中安装会话记录及 `installations/<会话 ID>/` 中的完整日志；不可撤销。删除后自动切换到其他会话，没有会话时恢复终端初始化界面。

仅允许删除已完成、失败、取消或中断的安装会话；排队、安装中、停止中、诊断中以及后台清理尚未完成的会话禁止删除。删除不会卸载引擎或删除独立 Python 环境及依赖。

## 安全与验证

前端禁用操作只是交互提示，后端同样校验运行状态、任务 ID 和删除路径；目录链接不得把清理范围重定向到其他目录。所有清理仅限应用自身的任务或安装日志目录。

回归测试覆盖配置完整性、零值与关闭开关、输出根目录、运行状态保护、磁盘与数据库持久化删除、保留产物访问、删除目标路径校验，以及真实浏览器中的右键、导出、复用和确认流程。
