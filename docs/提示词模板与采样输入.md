# 提示词模板与采样输入

## 直接输入

新建训练的“预览图”参数中，采样提示词不再填写文件路径。直接输入文本即可，每行代表一个采样提示词；留空表示不提供采样提示词。Kohya/Musubi 支持目标引擎允许的行内选项，AI Toolkit 将每行作为普通文本提示词处理。

## 模板管理

左侧“提示词模板”页面支持新建、编辑、删除和搜索模板。模板用于复制内容，不建立任务与模板之间的动态引用：将模板用于新建训练后，表单保存的是当时的文本快照，之后编辑模板不会修改旧任务。训练表单也可以把当前文本保存为模板，或将模板追加/替换到输入框。

## 引擎适配

主程序内部统一保存文本。Kohya 和 Musubi 在提交任务时才在任务目录生成 `sample_prompts.txt`，并在原生配置中引用该内部文件，因此不会要求用户维护提示词路径。AI Toolkit 直接生成 `sample.prompts` 列表。

导出 LP 完整备份时，提示词随 JSON 保存；导出引擎原生配置时，界面会另外提供配套的 `sample_prompts.txt` 下载。跨训练器迁移时，优先使用 LP 完整备份，原生格式中的路径、行内参数和采样字段仍需按目标引擎检查。

旧的 Kohya/Musubi 原生配置若仍包含提示词文件路径，导入时会跳过该字段并提示用户，避免把路径误当作实际提示词；请手动粘贴文件内容或使用模板。
