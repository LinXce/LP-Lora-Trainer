# 引擎复制入口

把完整训练引擎目录放到这里，每个一级子目录是一份安装实例：

```text
engine/
├─ kohya_ss/
├─ kohya_ss-old/
└─ ai-toolkit/
```

- 目录名可以自定义，不是唯一识别依据。
- 适配器应识别引擎原有结构，不要求改动上游源码。
- 同类引擎的不同版本共用对应的 `adapters/<engine>/`。
- 复制源码后还需要检查 Python、依赖与必要子模块；没有环境时不能启动训练。
- 用户复制的引擎默认用户管理，应用不自动更新、覆盖或删除。
- 新版本优先放入新目录，不覆盖活动任务使用的源码。
- 此目录内容不纳入应用版本控制；安装清单写到 `data_root/manifests/`。

目前仅建立入口目录，自动发现、登记与运行尚未实现。
