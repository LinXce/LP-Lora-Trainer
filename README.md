# LP LoRA Trainer

独立桌面 LoRA 训练管理应用，训练产物主要面向 ComfyUI 使用，但不依赖 ComfyUI。

## 已确定的架构

- 窗口：pywebview，Windows 使用 WebView2。
- 界面：Vue 3 + TypeScript + Vite。
- 后端：Python + FastAPI + Uvicorn，本机 HTTP + SSE。
- 训练：独立任务监管进程调用原生引擎 CLI。
- 引擎：直接复制到 `engine/`，由 `adapters/` 对应引擎的适配器识别。
- 版本：同一引擎多安装实例共存，提交任务时固定实例及代码/环境记录。

## 当前状态

已创建目录骨架、模块职责说明、公共数据类型和适配契约。
**尚未实现可启动的桌面应用、环境安装或真实训练。** 适配器文件只预留实现入口，不宣称已支持引擎运行。

这个阶段没有下载依赖、复制第三方引擎、运行原型或进行性能验证。依赖版本、锁文件和启动命令将在模块实现阶段补齐。

## 引擎目录示例

```text
engine/
├─ kohya_ss/
├─ kohya_ss-old/
└─ ai-toolkit/
```

目录名不是引擎身份。同类引擎的多个安装实例共享一个适配器。只复制源码不代表依赖齐全，完整运行环境需要另外检查。
